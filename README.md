PLANEJAMENTO DE TESTES:

Foi desenvolvido, neste branch, um código para controlar dois LEDs: um LED pisca por segundo e o outro pisca a cada meio segundo.

DETALHES DO FUNCIONAMENTO: 
0 segundo: ambos apagados; 
0,5 segundo: LED1(azul) acende e LED2(vermelho) apagado;
1 segundo: LED1(azul) acende e LED2(vermelho) acende, formando uma terceira cor de LED(rosa);
A partir deste momento, o looping se inicia.
